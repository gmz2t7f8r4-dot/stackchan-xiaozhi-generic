# StackChan Xiaozhi Generic（中文）

完整中文说明见项目主页：[README.md](README.md)。

本仓库是面向 M5Stack CoreS3 StackChan 的通用增强固件，包含摄像头、舵机、
灯带、MCP 动作以及原厂 StackChan World App 蓝牙舞蹈兼容。公开版不包含
私人角色、照片、凭据、设备标识或生产服务器地址。

快速开始：

```bash
idf.py set-target esp32s3
idf.py build
idf.py -p <PORT> flash monitor
```

许可证与上游归属见 [NOTICE.md](NOTICE.md)。
